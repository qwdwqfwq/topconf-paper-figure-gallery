## ギャラリーについて

6つの主要ML / AI学会の2023〜2026年のFigure 1・ティーザー図を収録しています。概念図、システム、処理フロー、モデル構造、タスク概要などを、論文の順位ではなくレイアウトの参考として提供します。各カードには原論文へのリンク、学会、年、著者、視覚パターンを記載しています。

- 学会、年、採択区分、視覚パターンで絞り込み、タイル状の一覧と拡大表示で閲覧できます。
- 対象年のICLR、ICML、NeurIPSのOral / Spotlight / Best・Outstanding図には金・銀・赤のバッジを表示します。
- タイトル、著者、キーワードを検索できます。例：`DPO`、`robot`、`gaussian`、`agent`。
- 25以上のルールで標準的なmatplotlibグラフ、単純な表、GUI画面、注記のない写真集を除外した後、すべての図を人が確認します。[手法](docs/METHODOLOGY.md)を参照してください。
- ギャラリーはバックエンドもビルドも不要な静的サイトです。
- 再現可能な処理：会議録索引 → PDF取得 → Figure 1切り抜き → 品質評価 → dHash重複除去 → 手動確認。

### 🛠️ FigureForge Beta

論文を説明すると、3,452枚の学会図をレイアウトの参考にしてFigure 1の下書きを作成します。登録不要で、自分のAPIキーを使いブラウザ上で実行します。 **[FigureForgeを試す →](https://qwdwqfwq.github.io/topconf-paper-figure-gallery/forge/)**

<p align="center"><img src="docs/figureforge-examples/figureforge-workflow.gif" alt="FigureForge" width="920"></p>

**[▶ 完全デモ動画 · 3分23秒 · 音声あり](https://qwdwqfwq.github.io/topconf-paper-figure-gallery/docs/demo.html)**

[![完全デモ動画 · 3分23秒 · 音声あり](assets/figureforge-demo-poster-en.png)](https://qwdwqfwq.github.io/topconf-paper-figure-gallery/docs/demo.html)

1. **論文を入力：** タイトルと要旨を貼り付けるか、PDFをアップロードしてステップ1のモデルに概要・構造・処理・結果の関連箇所を要約させます。「入力 → 手法 → 出力」を一文で書いても構いません。

2. **パターンを選択：** システムやエージェントは`framework`、処理フローは`pipeline`、モデル内部は`architecture`、視覚的比喩は`conceptual`を選びます。`teaser`と`taxonomy`もあります。

3. **参考図を選択：** CLIP + BM25で3,452枚を検索し、関連度を表示します。二段階モードは同じ型を最低4枚、最大10枚、直接モードは2〜4枚選びます。

   ![FigureForgeで作図](forge/tutorial/02_pick_refs.png)

4. **分析してから生成：** 視覚モデルが配置、要素、配色、階層を整理し、代表的な4〜6枚を選んでから下書きを生成します。

   ![FigureForgeで作図](forge/tutorial/03_analyze.png?v=20261002)

5. **モードとキーを設定（VPN不要の [Nonelinear API](https://nonelinear.com.cn) を推奨。合言葉「灵感画廊」で20元分のクレジットを受け取り）、ダウンロード：** SVGはFigma / draw.io / Illustratorでテキストを編集でき、ビットマップはPPT / Figmaで確認する論文向けの配置を生成します。キーはローカルブラウザにのみ保存されます。

> FigureForgeは学会図のレイアウトを参考に、パネル構成、比較の流れ、抑えた配色を下書きに反映します。

> ![FigureForge](forge/tutorial/compare.png?v=20261002)

## 🧭 視覚パターン

タグは研究分野ではなく、図の視覚的な役割を表します。

| タグ | 意味 | 例 |
|---|---|---|
| `conceptual` | 中心的なアイデアを示す視覚的比喩 | DPO, Tree of Thoughts, HippoRAG |
| `framework` | システムやエージェントの全体像 | HuggingGPT, SWE-agent, MetaGPT |
| `pipeline` | 段階的なデータフロー | LRM, VidMan, LiveStar |
| `architecture` | 内部の層とテンソル接続 | BLIP-2, Caduceus, Medusa |
| `taxonomy` | タスク・能力・データの全体像 | EmbodiedBench, SimWorld |
| `teaser` | 画像と文章を組み合わせたデザイン | VIMA, PixArt-α |
