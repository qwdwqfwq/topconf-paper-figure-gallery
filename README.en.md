## About the gallery

Top-Conf Figure Gallery collects Figure 1 and teaser figures from six ML/AI conferences in 2023–2026: concept diagrams, system frameworks, pipelines, architectures and task overviews. It provides layout inspiration rather than a paper ranking. Each card links to the paper and records its venue, year, authors and visual-pattern tag.

- Filter by venue, year, acceptance tier and visual pattern; browse a masonry layout and lightbox.
- Oral, Spotlight and Best / Outstanding figures carry gold, silver and red badges for ICLR, ICML and NeurIPS in the indexed years.
- Search titles, authors and keywords, including `DPO`, `robot`, `gaussian` and `agent`.
- Each figure is manually reviewed after over 25 heuristic rules remove default matplotlib charts, plain tables, GUI screenshots and unlabeled photo sets. See [methodology](docs/METHODOLOGY.md).
- The gallery is a static site with no backend or build requirement.
- Reproducible pipeline: proceedings index → PDF download → Figure 1 crop → quality scoring → dHash deduplication → manual review.

### 🛠️ FigureForge Beta

Describe your paper and use 3,452 conference figures as layout references for your Figure 1 draft. No registration is required; the workflow runs in your browser and uses your API key. **[Try FigureForge →](https://qwdwqfwq.github.io/topconf-paper-figure-gallery/forge/)**

<p align="center"><img src="forge/demo-forge.gif?v=20261002" alt="FigureForge" width="560"></p>

**[▶ Full demo video · 3:23 · with audio](https://qwdwqfwq.github.io/topconf-paper-figure-gallery/docs/demo.html)**

[![Full demo video · 3:23 · with audio](assets/figureforge-demo-poster-en.png)](https://qwdwqfwq.github.io/topconf-paper-figure-gallery/docs/demo.html)

1. **Describe the paper:** paste the title and abstract, upload a PDF for the Step 1 model to read and summarize relevant overview, architecture, pipeline and results sections, or state the input → method → output story.

2. **Choose a pattern:** `framework` for systems or agents, `pipeline` for end-to-end flows, `architecture` for internal model structure, `conceptual` for visual metaphors, or `teaser` / `taxonomy`.

3. **Select references:** CLIP + BM25 searches all 3,452 figures and shows relevance scores. Two-stage mode uses at least 4 same-pattern references, up to 10; direct mode uses 2–4.

   ![Draw with FigureForge](forge/tutorial/02_pick_refs.png)

4. **Two stages — analyze, then generate:** a vision model summarizes layout, elements, palette and hierarchy, selects 4–6 representative figures, then generates the draft.

   ![Draw with FigureForge](forge/tutorial/03_analyze.png?v=20261002)

5. **Choose a mode, enter your key (recommended: [Nonelinear API](https://nonelinear.com.cn), accessible without a VPN; mention「灵感画廊」to receive ¥20 in credits), and download:** SVG mode supports editable text in Figma / draw.io / Illustrator; bitmap mode provides a publication-style layout for checking in PPT / Figma. Your key is stored only in your local browser.

> FigureForge uses top-conference figures as layout references to preserve panel grids, comparison narratives and restrained palettes in the draft.

> ![FigureForge](forge/tutorial/compare.png?v=20261002)

## 🧭 Visual patterns

Tags describe visual function, not the paper’s research field.

| Tag | Meaning | Examples |
|---|---|---|
| `conceptual` | Visual metaphor for a core idea | DPO, Tree of Thoughts, HippoRAG |
| `framework` | System or agent overview | HuggingGPT, SWE-agent, MetaGPT |
| `pipeline` | Staged end-to-end data flow | LRM, VidMan, LiveStar |
| `architecture` | Internal layers and tensor connections | BLIP-2, Caduceus, Medusa |
| `taxonomy` | Overview of tasks, capabilities or data | EmbodiedBench, SimWorld |
| `teaser` | Designed composition of images and text | VIMA, PixArt-α |

## 🚀 Quick start

Browse online: [GitHub Pages](https://qwdwqfwq.github.io/topconf-paper-figure-gallery/).

Run locally:

```bash
git clone https://github.com/qwdwqfwq/topconf-paper-figure-gallery.git
cd topconf-paper-figure-gallery
python -m http.server 8000
```

[http://localhost:8000](http://localhost:8000)

Or double-click `index.html`; metadata is inlined in `assets/figures.js`, so the gallery does not require a network connection.
