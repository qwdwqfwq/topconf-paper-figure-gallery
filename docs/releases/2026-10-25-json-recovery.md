# 2026-10-25 步骤四 JSON 恢复与空白结果修复

用户明确授权解除本次场景 JSON 解析、节点提取与可见性检查、对应测试及发布锁记录的冻结。历史冻结档案和 19:30 标签保留。

## 原因与修复

本次原始模型返回包含属性分隔符、非法值及多余引号等 JSON 错误。旧解析回退误将 9 个 regions 分区透明框作为可编辑节点，实际节点未进入导出，因此产生空白 PPTX。

- 按盘点、场景、诊断、修补各自结构恢复。只修复可确定的标点错误；无法确定的值不猜测，逐条隔离并记录原因，合法相邻条目保留。
- 场景提取明确排除 regions、canvas、recovery 元数据。节点逐条校验；新增操作中的合法节点保留，更新操作保持原子性，防止部分更新破坏已有对象。
- 检查可见文字、图形、图像和路径，过滤透明、隐藏、画布外及仅白色背景的结果。只有透明框时明确报告未生成可用内容，不提供空白草稿。
- 有可见内容但验收未通过时可导出草稿；恢复或隔离记录进入审计，不冒充完整验收通过。
- 保持首次整图重建后最多一轮局部修补，不自动整图重来。原始像素尺寸、模型及请求参数、提示词、图片发送编码、导出器和格式保持不变。

## 验证

使用本次实际下载的 figure-forge-reconstruction-response.json 回放三个原始响应：恢复 114 个盘点项、233 个可用重建节点（72 个文字节点）、141 个有效修补操作。场景隔离 4 个无效条目并记录原因。浏览器渲染检测到 3,215,688 个非白可见像素，原生 PPTX 导出 323,381 字节。

回放通过真实请求解析入口、SVG 渲染及 PPTX 导出。测试中的照片裁片源使用同尺寸空画布，故不代表照片内容保真验证；没有发起付费模型调用。另覆盖混合合法/非法新增节点、透明框不能交付、格式错误隔离、分区元数据排除、单轮修补限制、回退、草稿导出，以及既有图片传输回归。

发布锁仅记录本次授权涉及的 forge/index.html、forge/reconstruction-core.mjs、forge/bitmap-evidence.mjs 和新增 forge/bitmap-response.mjs。历史冻结校验器不变；其旧基线差异仍如实报告。
